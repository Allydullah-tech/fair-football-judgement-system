# Fair Football Judgement System (FFJS)

## Project Description

The Fair Football Judgement System (FFJS) is a web-based platform developed to improve transparency, fairness, and accountability in football tournament management.

The system allows administrators, referees, team managers, and viewers to access football competition information through a centralized platform.

---

## Main Features

### Admin Module
- Manage teams
- Manage matches
- Manage referees
- View reports
- Manage prize distribution

### Referee Module
- View assigned matches
- Submit match results
- View match history

### Manager Module
- Register teams
- View fixtures
- Check results
- Monitor prizes

### Viewer Module
- View standings
- View fixtures
- View results
- View prize distribution
